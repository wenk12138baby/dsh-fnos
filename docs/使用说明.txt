一、怎么安装 fpk
--------------------------------------------------------------------------------

【前置条件】

  1.飞牛应用中心必须已安装 Node.js v24（nodejs_v24）。
  这是硬性依赖，没装的话应用启动会失败。
  路径：应用中心 → 搜索 "Node.js" → 安装 v24 版本。
 
  2. 3080和13080端口无占用。

【安装步骤】
  1. 打开飞牛 Web 管理界面，用管理员账号登录。

  2. 进入「应用中心」。

  3. 找到右上角的「手动安装」按钮（一般在应用中心页面右上）。
     不同版本位置可能略有差异，也可能是齿轮图标或「⋮」菜单里。

  4. 选择本地的 DeepSeekHarness-0.2.1-rc.2-温克baby.fpk 文件上传。

  5. 等待安装完成（约 1-2 分钟，包比较大，需要解压）。

  6. 安装完成后，桌面上会出现「DeepSeek Harness」图标。

  7. 点击图标即可打开。首次启动需要初始化，等 1-3 分钟左右（根据硬件相关）。期间打开会提示访问被拒绝，正常现象，稍等即可。

  8.如果安装后启动失败，再次点击启动提示端口3080或者13080占用，确认无风险后（问ai）使用：
        sudo fuser -k -n tcp 3080
        sudo fuser -k -n tcp 13080

   结束进程后重试。

二、怎么登录账号
--------------------------------------------------------------------------------

  本应用有两种使用方式，任选其一。

  ══════════════════════════════════════════════════════════════════════════
  方式一：API Key 登录（推荐，最简单）
  ══════════════════════════════════════════════════════════════════════════

    1. 打开应用，进入「设置 → 模型」。

    2. 找到 DeepSeek 提供方，填入你的 API Key。
       API Key 获取地址：https://platform.deepseek.com/api_keys

    3. 保存后即可使用。API Key 方式不受网络环境影响，最稳定。

  ══════════════════════════════════════════════════════════════════════════
  方式二：DeepSeek 账号登录（需要 SSH 隧道）————最简单交给AI
  ══════════════════════════════════════════════════════════════════════════

    为什么需要隧道？
    ----------------
    DSH 的账号登录采用 OAuth 回调机制，回调地址被硬编码限制为
    localhost / 127.0.0.1。这是安全设计，不是 bug。
    你从局域网 IP（如 http://192.168.88.12:3080）访问时，OAuth 回调会
    指向你自己电脑的 127.0.0.1，而 DSH 跑在 NAS 上，两边对不上，
    所以点击登录会弹出窗口但无法完成。

    解决办法是把 NAS 的端口映射到你电脑的 localhost。

    【第一步：开启 SSH 端口转发】
    在 NAS 上执行（需要 root 或 sudo）：
        sudo sshd -T | grep -i allowtcpforwarding

    如果显示 allowtcpforwarding no，需要改成 yes：
        sudo sh -c 'printf "AllowTcpForwarding yes\n" > /etc/ssh/sshd_config.d/trim_sshd.conf'
        sudo systemctl restart ssh
        sudo sshd -T | grep -i allowtcpforwarding    # 应显示 yes

    【第二步：在你自己电脑上建隧道】
    Windows 打开 PowerShell，Mac/Linux 打开终端，执行：

        ssh -N -L 3080:127.0.0.1:13080 你的飞牛用户名@飞牛的IP

    例如：
        ssh -N -L 3080:127.0.0.1:13080 温克Baby@192.168.xx.x

    输入密码后窗口会「卡住不动」——这是正常的，说明隧道已建立，
    不要关闭这个窗口。

    【第三步：用带 token 的地址打开】
    先取出当前的登录 token。在 NAS 上执行：

        grep -o 'token=[A-Za-z0-9_-]*' /vol5/@appdata/DeepSeekHarness/gateway.log | tail -1

    会输出类似：
        token=Easo7fukZFCjepNVRk6NZJbsHYbrkpyC3n9cjGywHJA

    把 token 拼到这个地址后面，在你的浏览器里打开：

        http://localhost:3080/?token=上面取到的token

    完整示例：
        http://localhost:3080/?token=Easo7fukZFCjepNVRk6NZJbsHYbrkpyC3n9cjGywHJA

    注意：
      - 必须是 localhost，不能是 NAS 的 IP
      - 必须带 ?token=...，不带会显示 401
      - 建议用无痕窗口，避免旧 cookie 干扰

    【第四步：点击登录】
    页面正常打开后，进入「设置 → 账号」，点击登录 DeepSeek 账号。
    这次会正常跳转并完成授权。

    登录成功后，cookie 已保存在 NAS 上，之后关闭隧道、
    直接用 NAS 的 IP 访问也是已登录状态，不需要重复操作。

三、怎么安装插件
--------------------------------------------------------------------------------

  1. 打开应用，在左侧栏找到「插件」面板（或「设置 → 插件」）。

  2. 进入「插件市场」页签。

  3. 搜索插件名，点击「安装」。

  4. 等待安装完成（会自动下载依赖，需要联网）。

  5. 部分插件安装后需要重启应用才生效：
     应用中心 → DeepSeek Harness → 重启。

五、不推荐（fnOS 亲测）
--------------------------------------------------------------------------------

  01. dsh-workbuddy-connect
      桌面端白嫖，fnOS 上用不了。
      原因：它的原理是读取 WorkBuddy 桌面 App 的登录凭据，
      而凭据用 WorkBuddy 自己的 Electron 私有绑定加密，
      必须在 Windows/Mac 本机上运行 .exe 才能解密。
      fnOS 是 Linux 系统，没有这些东西，装上也读不到凭据，
      会一直报「网关暂不可达」或「no adapter registered」。

  02. dsh-deepseek-web-login
      白嫖网页版 DeepSeek，必封号 1 天。
      它通过模拟浏览器登录 chat.deepseek.com 来白嫖网页版额度，
      这违反 DeepSeek 的服务条款，会被检测并封禁。
      想白嫖的话用 dsh-our-free-model，那个是正规渠道聚合。

  03. dsh-purge-community
      破甲，解除 AI 的一切伦理道德限制。
      很爽，但喜提封号。
      会绕过模型的安全对齐，触发上游风控，账号必封。
      不建议在有价值的账号上使用。

六、已知问题
--------------------------------------------------------------------------------

  【问题：卸载后端口仍被占用】
  现象：在应用中心卸载 DeepSeek Harness 后，3080 和 13080 端口
        仍被占用，重新安装时提示端口冲突。

  原因：卸载时后台进程未被完全清理，导致残留进程继续持有端口。

  解决：通过 SSH 登录 NAS，分别执行以下命令杀死残留进程：

        sudo fuser -k -n tcp 3080
        sudo fuser -k -n tcp 13080

  执行后端口即被释放，可以重新安装。

  验证是否已释放：
        ss -tln | grep -E ':3080|:13080'

  没有输出说明已释放干净。

  【其他排障常用命令】

  查看应用日志：
        tail -50 /volx（x为存储空间号）/@appdata/DeepSeekHarness/gateway.log

  查看进程是否在运行：
        ps aux | grep DeepSeekHarness | grep -v grep

  查看端口监听：
        ss -tln | grep -E ':3080|:13080'

  手动重启应用：

        看不懂代码直接商店中停用

        export TRIM_APPDEST=/volx（x为存储空间号）/@appcenter/DeepSeekHarness
        export TRIM_PKGHOME=/volx（x为存储空间号）/@apphome/DeepSeekHarness
        export TRIM_PKGVAR=/volx（x为存储空间号）/@appdata/DeepSeekHarness
        export TRIM_SERVICE_PORT=3080
        export TRIM_USERNAME=deepseek-harness
        sudo bash /var/apps/DeepSeekHarness/cmd/main stop
        sudo bash /var/apps/DeepSeekHarness/cmd/main start

  检查插件工具链：
        /volx（x为存储空间号）/@appcenter/DeepSeekHarness/.local/bin/pnpm --version
        /volx（x为存储空间号）/@appcenter/DeepSeekHarness/.local/bin/npm --version
